**Purpose:** formalise when internal AC time can substitute for model size, and when extra size cannot remove a sequential time requirement.

This note connects [[AC Mathematical Setup]], [[Temporal and Iterative Tasks]], and [[Error Accumulation]]. It is a mean-field predictive theory, not an exact theorem. The central question is: for a fixed target accuracy, can we spend more neurons, fibres, or stored synaptic structure to reduce the internal update budget $t$?

## 1. Resource Measures

Let the family-level AC resources be

$$
\theta_{\mathrm{family}}
=
(\mathcal A,\mathcal F,n,k,p,\beta).
$$

A trained/evaluated instantiated model has realised graph masks and weights:

$$
\theta_{\mathrm{inst}}
=
(\mathcal A,\mathcal F,G,W^\star,k).
$$

The number of areas is

$$
a=|\mathcal A|.
$$

Two useful size measures are

$$
S_{\mathrm{neurons}}(\theta_{\mathrm{family}})=an
$$

and

$$
S_{\mathrm{synapses}}(\theta_{\mathrm{family}})
\approx
|\mathcal F|pn^2.
$$

In this note, write

$$
S_{\mathrm{model}}=S(\theta_{\mathrm{inst}})
$$

for whichever fixed model-size measure is being varied. This includes neurons, areas, fibres, realised graph structure, and learned weights. For mean-field size sweeps, $S(\theta_{\mathrm{family}})$ denotes the expected size before drawing the graph.

For tasks with a structured input, especially pointer chasing, also distinguish the size of the current instance representation:

$$
S_{\mathrm{instance}}(q).
$$

For a pointer table $M$, this may include the neural representation of the table itself. If shortcut tables are provided as part of the input, they belong to instance size, not fixed learned model size:

$$
S_{\mathrm{instance}}(M,L).
$$

The internal update budget $t$ is separate:

$$
t\notin \theta_{\mathrm{family}},
\qquad
t\notin \theta_{\mathrm{inst}}.
$$

Thus a run is described by model size, instance representation size, and time:

$$
(\theta_{\mathrm{inst}},S_{\mathrm{instance}},t).
$$

For a task distribution $\mathcal Q$, define

$$
A_{\mathcal Q}(S_{\mathrm{model}},S_{\mathrm{instance}},t)
=
Acc_{\mathcal Q}(\theta_{\mathrm{inst}},t),
$$

where $S_{\mathrm{model}}=S(\theta_{\mathrm{inst}})$. When the instance representation is fixed by the benchmark, this is abbreviated as $A_{\mathcal Q}(S,t)$.

## 2. Marginal Value of Time and Size

For discrete update budgets, define the marginal value of one more internal update as

$$
\Delta_t A_{\mathcal Q}(S,t)
=
A_{\mathcal Q}(S,t+1)-A_{\mathcal Q}(S,t).
$$

For a size increase $\Delta S$, define

$$
\Delta_S A_{\mathcal Q}(S,t)
=
A_{\mathcal Q}(S+\Delta S,t)-A_{\mathcal Q}(S,t).
$$

When a smooth approximation is appropriate, an isoaccuracy curve satisfies

$$
dA
=
\frac{\partial A}{\partial S}dS
+
\frac{\partial A}{\partial t}dt
=0.
$$

Therefore the local tradeoff slope is

$$
\frac{dS}{dt}
=
-
\frac{\partial A/\partial t}
{\partial A/\partial S}.
$$

Time and size are locally substitutable only when both marginal effects are meaningful. If

$$
\frac{\partial A}{\partial t}\approx 0,
$$

then more time cannot be exchanged for less size. If

$$
\frac{\partial A}{\partial S}\approx 0,
$$

then increasing size cannot compensate for too little time.

## 3. Static Tasks: Weak Time-Size Substitution

For static classification, the target is already determined by the cue:

$$
q\mapsto y.
$$

As in [[Static Tasks]], internal time changes the readout margin

$$
m_y(t)
=
o_y(t)-\max_{z\neq y}o_z(t).
$$

The success condition is

$$
m_y(t)>0.
$$

Extra size can improve static performance by increasing separation between assemblies, reducing random overlap, or lowering crosstalk. Extra time can improve performance only while it increases the correct margin.

Once the representation has settled,

$$
m_y(t+1)\approx m_y(t),
$$

so

$$
\Delta_t A_{\mathcal Q}(S,t)\approx 0.
$$

At that point, time is not a useful substitute for size. The static-task tradeoff is therefore mostly an accuracy-capacity tradeoff, not a true execution-depth tradeoff.

## 4. Iterative Tasks: Size Can Encode Shortcuts

For pointer chasing, the target is

$$
s_L=M^L(s_0).
$$

With a one-step transition mechanism, one symbolic transition requires approximately $c$ AC updates. Temporal reuse gives

$$
t\geq cL.
$$

This is the basic linear time-depth frontier from [[Temporal and Iterative Tasks]].

Size can reduce time only if it changes the available transition operators. For an unseen table, these operators cannot be assumed to be hidden in fixed learned weights. They must either be included in the instance representation, generated by a preprocessing mechanism, or computed internally using time.

For example, instead of representing only the one-step map

$$
M,
$$

the model may also store shortcut maps

$$
M^2,\quad M^4,\quad M^8,\quad \dots.
$$

Then depth $L$ can be decomposed in binary:

$$
L=\sum_{q=0}^{h} b_q2^q,
\qquad
b_q\in\{0,1\}.
$$

The model can compute the final state by applying only the selected shortcut maps. Starting from

$$
z_0=s_0,
$$

apply

$$
z\leftarrow M^{2^q}(z)
$$

for each $q$ with $b_q=1$. After all selected powers have been applied,

$$
z=M^L(s_0).
$$

This reduces the number of symbolic transition applications from

$$
L
$$

to at most

$$
\lfloor \log_2 L\rfloor+1.
$$

The price is additional table-specific memory. If one transition table over $N$ states costs $S_M(N)$ to represent, then temporal reuse has

$$
S_{\mathrm{instance}}(M)
\approx
S_M(N).
$$

Binary shortcuts cost approximately

$$
S_{\mathrm{instance}}(M,L)
\approx
S_M(N)\left(\lfloor \log_2 L\rfloor+1\right).
$$

This is a genuine time-size tradeoff:

$$
\text{larger instance representation}
\quad\Rightarrow\quad
\text{fewer dependent internal steps}.
$$

*Figure: schematic scaling regimes. Temporal reuse keeps transition memory small but uses time linear in $L$; jump-table shortcuts spend more memory to reduce execution depth.*

Shortcuts are useful only if they are reliable. Define shortcut-specific error

$$
\epsilon_q(c,S)
=
\Pr[\widehat{M^{2^q}}_c(s)\neq M^{2^q}(s)].
$$

For a binary expansion

$$
L=\sum_q b_q2^q,
$$

the shortcut path-success approximation is

$$
Acc_{\mathrm{shortcut}}(L,c,S)
\approx
\prod_{q:b_q=1}
\left(1-\epsilon_q(c,S)\right).
$$

Shortcuts help when the reduction from $L$ one-step transitions to at most $\lfloor\log_2 L\rfloor+1$ shortcut transitions outweighs any increase in shortcut-specific error. They may fail to help if large powers $M^{2^q}$ are noisy, ambiguous, or expensive to represent.

## 5. Three Regimes

For a depth limit $L_{\max}$, the main regimes are:

| Regime | Stored transition structure | Symbolic steps for depth $L$ | Size scaling |
|---|---|---|---|
| temporal reuse | $M$ | $L$ | $S_M(N)$ |
| binary shortcuts | $M^{2^q}$ for $q\leq \log_2 L_{\max}$ | $O(\log L)$ | $O(S_M(N)\log L_{\max})$ |
| direct depth table | $M^\ell$ for every $\ell\leq L_{\max}$ | $O(1)$ if $L$ selects a stored map | $O(S_M(N)L_{\max})$ |

The direct table regime gives constant symbolic execution time, but it pays linear memory in the maximum depth. For unseen tables, such shortcuts must either be supplied as part of the input representation or computed internally. They cannot be assumed to appear for free.

## 6. Reliability-Constrained Tradeoff

Size affects not only how many shortcuts are available, but also how reliable each transition is. Let $\epsilon(c,S)$ be the one-step transition error when each symbolic step receives $c$ internal updates in a model of size $S$.

A useful approximation is

$$
\epsilon(c,S)
\approx
\epsilon_\infty(S)+\epsilon_0(S)\rho(S)^c,
\qquad
0<\rho(S)<1.
$$

Larger models may reduce the irreducible error floor:

$$
\epsilon_\infty(S+\Delta S)<\epsilon_\infty(S),
$$

or speed up settling:

$$
\rho(S+\Delta S)<\rho(S).
$$

For a depth-$L$ task, the path-correctness approximation is

$$
Acc_{\mathcal Q_L}(S,t)
\approx
\mathbf 1\{t\geq cL\}
\left(1-\epsilon(c,S)\right)^L.
$$

For target accuracy $\alpha$, a sufficient reliability condition is

$$
L\epsilon(c,S)
\lesssim
-\log \alpha.
$$

Thus $S$ and $t$ are both constrained:

$$
t\geq cL
$$

and

$$
\epsilon(c,S)\lesssim \frac{-\log \alpha}{L}.
$$

Extra size can reduce the second constraint. It cannot remove the first constraint unless it also supplies a different algorithmic structure, such as jump shortcuts.

## 7. Fixed Budget Optimisation

Suppose the total internal budget is $t$ and $c$ updates are allocated per symbolic transition. For temporal reuse,

$$
L_{\max}(t,c,S,\alpha)
\approx
\min\left\{
\left\lfloor\frac{t}{c}\right\rfloor,
\frac{-\log \alpha}{\epsilon(c,S)}
\right\}.
$$

If $c$ is a design choice, the best predicted depth is

$$
L_{\max}(t,S,\alpha)
\approx
\max_{c\in\mathbb N_+}
\min\left\{
\left\lfloor\frac{t}{c}\right\rfloor,
\frac{-\log \alpha}{\epsilon(c,S)}
\right\}.
$$

This formula gives the core engineering tradeoff:

- small $c$: many transitions fit into time, but each one is noisy;
- large $c$: each transition is reliable, but fewer transitions fit;
- larger $S$: can reduce $\epsilon(c,S)$, shifting the optimum.

## 8. When Time and Size Are Tradeable

Time and size are tradeable when extra size changes one of these quantities:

$$
c(S),
\qquad
\epsilon(c,S),
\qquad
\text{or}
\qquad
\text{available shortcut maps}.
$$

Examples:

- adding neurons or fibres reduces crosstalk, lowering $\epsilon(c,S)$;
- increasing $n$ with fixed $k$ lowers random assembly overlap;
- storing jump maps reduces effective transition depth from $L$ to $O(\log L)$;
- storing direct depth maps can reduce symbolic execution to $O(1)$ for bounded $L$.

In these cases, larger $S$ can reduce the amount of internal time needed for a fixed accuracy target.

## 9. When Time and Size Are Not Tradeable

Time and size are not freely tradeable when the task contains a causal dependency that has not been encoded as a shortcut.

For pointer chasing with only the one-step table available,

$$
s_{\ell+1}=M(s_\ell)
$$

must be applied sequentially. Even a larger state assembly cannot know $s_{\ell+1}$ before $s_\ell$ has been represented, unless the larger model stores or computes a shortcut map.

Therefore, under temporal reuse,

$$
t=\Omega(L)
$$

for depth-$L$ pointer chasing.

This is consistent with the constant-time locality argument in the thesis appendix: fixed-time models can only use a bounded amount of sequential dependency unless the relevant dependency has already been compressed into the model or input representation.

## 10. Experimental Signatures

The theory predicts these measurements.

| Measurement | Prediction |
|---|---|
| accuracy over $(S,t)$ for fixed $L$ | isoaccuracy contours slope downward only where both size and time help |
| $L_{\max}$ vs $t$ at fixed $S$ | roughly linear until error accumulation dominates |
| $L_{\max}$ vs $S$ at fixed $t$ | improves only if size lowers transition error or supplies shortcuts |
| temporal reuse vs jump shortcuts | jump shortcuts reduce slope of required time from $L$ toward $\log L$ |
| shortcut error $\epsilon_q$ vs $q$ | shortcuts help only if larger powers remain reliable |
| static-task accuracy vs $(S,t)$ | time saturates after settling; size may still improve separation |

The main claim is:

$$
\text{time can substitute for size only when the computation can reuse a smaller mechanism without losing reliability.}
$$

For iterative tasks, extra size can reduce time by storing shortcut structure. Without shortcuts, internal time remains the resource that executes the dependent sequence.
